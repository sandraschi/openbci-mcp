# Configuration

See `INSTALL.md` and environment variables in `README.md`.

## Cyton serial

Set `OPENBCI_SERIAL_PORT=COM3` (Windows) or `/dev/ttyUSB0` (Linux).

## Ganglion BLE

Set `OPENBCI_MAC_ADDRESS` to the device MAC.

## Streaming from OpenBCI GUI

Use `board_key=streaming` with multicast defaults `225.1.1.1:6677`.
